# 验收门禁与追踪矩阵 (ACCEPTANCE)

只有所有门禁项通过，且经本任务负责人（Antigravity）核验通过后，才可发出任务完成证书。

## 1. 逐步工作流门禁 (Step Flow Gate)
- [ ] 针对“创建小程序”类请求，界面具备逐步推进展示；
- [ ] 步骤具备清晰的阶段名称（如需求拆解、视图设计、逻辑编写、沙箱打包），且状态（`running` / `completed`）更新平滑，无卡顿死锁；
- [ ] 步骤支持折叠与展开查看执行细节。

## 2. 小程序交付卡片门禁 (Deliverable Card Gate)
- [ ] AI 生成的小程序不以海量原始代码占屏，而是呈现为结构化的交付物卡片；
- [ ] 卡片包含清晰的小程序名称（如“打地鼠小游戏”）、版本号、说明及状态标签；
- [ ] 提供明确的操作入口：【🎮 立即试玩 / 运行】和【查看源代码】；
- [ ] 具备向下兼容能力：对已存在或回传的自包含 HTML 代码块能自动解析为可运行卡片。

## 3. 交互式沙箱试玩门禁 (Sandbox Runner & Whac-A-Mole Playability)
- [ ] 点击卡片【运行】按钮后，内嵌安全沙箱模态框或面板即刻唤起；
- [ ] 小程序在沙箱中成功加载并运行，无跨域报错；
- [ ] **打地鼠游戏真实可玩**：
  - 3x3 洞穴网格布局正常显示；
  - 地鼠随机从洞穴中冒出并自动缩回；
  - 玩家点击冒出的地鼠，击中动画生效且得分计数器实时 +1；
  - 倒计时时间递减（如 30 秒倒计时），归零后游戏结束，展示最终得分和重玩按钮；
  - 支持全屏试玩与退出关闭。

## 4. 磁盘安全与 GitHub Actions CI 门禁
- [ ] 开发机本地未执行任何构建（`npm run build`、`cargo build` 等），本地无多余大文件残留；
- [ ] GitHub Actions CI 流水线运行通过，前端与各端静态检查及单元测试全绿；
- [ ] 最终报告提供完整的 GitHub Commit、PR/Actions Run 凭证与可复现验证证据。
