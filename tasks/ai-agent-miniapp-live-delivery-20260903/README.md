# AI 智能体逐步工作与全平台交互式小程序交付运行任务

本目录是 `ai-agent-miniapp-live-delivery-20260903` 任务的权威规范目录。

## 1. 任务背景与目标
彻底解决全平台应用中 AI 助手仅作为问答（Q&A）输出大段代码文本的问题。
实现以下核心能力：
1. **逐步工作流展示（Step-by-Step Autonomous Workflow）**：当用户请求如“创建一个打地鼠的小程序”时，AI 能够进行结构化步骤规划与执行（需求分析、UI设计、逻辑编码、沙箱封装），并在界面中流式展示每一步的进度与状态；
2. **小程序产物交付卡片（MiniApp Deliverable Card）**：将生成的小程序（如打地鼠游戏）封装为独立的交互式卡片，展示小程序名称、图标、功能介绍与【立即运行】操作按钮，优雅折叠海量源代码；
3. **交互式安全沙箱运行（Interactive Sandboxed MiniApp Execution）**：用户点击后在应用内安全沙箱（Iframe Sandbox / Runner）中直接启动该小程序，支持完整的交互体验（打地鼠随机冒头、点击碰撞、实时计分、倒计时、结算与重置）；
4. **全平台覆盖**：保证桌面端（Electron / React）、Web 端（Next.js）及移动端规范契约的一致性。

## 2. 持续执行与验收原则
- 每轮执行开始前，必须读取本目录全部文件及关联 PRD；
- 开发机绝不进行应用构建、大型依赖下载或重型测试（严格遵循仓库 `AGENTS.md`）；
- 所有构建、打包和 E2E 验证必须在 GitHub Actions Runner 内跑通；
- 本任务负责人（Antigravity）将对 ChatGPT 每一轮交付的代码、事件流、可玩性与 Actions 凭证进行客观验收；未达 `ACCEPTANCE.md` 门禁不得输出完成证书。
