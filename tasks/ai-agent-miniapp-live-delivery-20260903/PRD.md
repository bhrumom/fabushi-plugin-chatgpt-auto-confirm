# 产品需求规范 (PRD) - AI 智能体逐步工作与交互式小程序交付运行

## 1. 用户故事与场景

### 场景 A：打地鼠小程序创建与即时试玩
1. **用户输入**：“帮我创建一个打地鼠的小程序，要有计分和倒计时。”
2. **AI 响应过程（逐步流式反馈）**：
   - 客户端显示 Agent 正在进行规划与逐步执行：
     - `步骤 1/4: 规划打地鼠游戏玩法、9宫格洞穴布局与倒计时规则 [已完成]`
     - `步骤 2/4: 构建自适应游戏界面与样式，绘制地鼠动画与洞穴背景 [已完成]`
     - `步骤 3/4: 编写随机地鼠冒头、点击击打、计分统计与结束判定逻辑 [已完成]`
     - `步骤 4/4: 打包为自包含安全 MiniApp 沙箱产物 [已完成]`
3. **交付结果（非长篇文本代码）**：
   - AI 伴随一句简短总结：“打地鼠小游戏已为您创建并打包完成，您可以点击下方卡片立即试玩！”
   - 会话中渲染一个精致的 **MiniApp 交付卡片**：
     - 图标：🐹（或地鼠专属矢量图标）
     - 标题：**打地鼠小游戏 (Whac-A-Mole)**
     - 描述：支持 3x3 随机地鼠冒头、30秒倒计时、实时积分统计及重玩机制。
     - 操作按钮：【🎮 立即试玩 / 运行】、【查看源代码】、【全屏】。
4. **用户试玩**：
   - 用户点击【🎮 立即试玩 / 运行】；
   - 聊天界面唤起安全沙箱模态框或内嵌面板；
   - 用户可直接在应用内用鼠标或触屏点击冒头的地鼠，分数即时增加，倒计时结束后提示最终得分并支持重新开始。

## 2. 功能详细规格

### 2.1 步骤状态卡片 (`StepTrackerCard`)
- 支持动态更新状态：`running`（运行中动画/Spinner）、`completed`（绿色打勾图标）、`failed`（红色错误提示）；
- 步骤列表可折叠/展开，展开时展示具体步骤执行细节。

### 2.2 小程序交付卡片 (`MiniAppDeliverableCard`)
- 属性：
  - `id`: 小程序唯一标识；
  - `title`: 小程序名称；
  - `version`: 版本号；
  - `description`: 功能简述；
  - `entryHtml`: 自包含 HTML 字符串（内置 CSS 和 JS 逻辑）；
  - `createdAtMs`: 交付时间戳。
- 交互：
  - 点击“运行/试玩”：呼起沙箱运行器；
  - 点击“查看代码”：展开/收起语法高亮的代码片段，并提供一键复制按钮。

### 2.3 安全沙箱运行器 (`MiniAppSandboxRunner`)
- 基于原生 `iframe`，添加安全沙箱隔离限制：`sandbox="allow-scripts allow-forms allow-same-origin-for-blob"`，禁止非法顶级导航与跨域越权；
- 支持自适应窗口大小；
- 提供标题栏、刷新重置按钮、全屏切换按钮和关闭按钮；
- 零外部依赖：打地鼠小程序资源完全内联自包含，脱网也可离线运行。
