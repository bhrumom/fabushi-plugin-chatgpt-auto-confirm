# 产品需求：iOS 外部小程序真实全链路自动化

## 用户问题

目前核心功能主要依赖真机人工验证，无法在每次构建前后快速、稳定地证明线上小程序搜索、外部安装、热更新和真实对话链路可用。UI 成功提示也不能证明 CLI、插件 runtime 与远端构件实际完成了工作。

## 产品目标

以 Mahayana CLI 为唯一业务事实源，建立类似 CDP 的版本化测试驱动接口，并先在 iOS Simulator/CI 中完成从干净新用户到真实外部小程序对话的自动化闭环：

1. 新用户没有预装插件。
2. 搜索线上官方“全球法布施”小程序。
3. 下载、验证并安装远端构件。
4. 在宿主不重新打包的情况下发现并应用热更新。
5. 向插件机器人发送确定性消息。
6. 使用 CLI/runtime 日志、安装收据和 correlation id 验证真实结果。

## 范围边界

- 本任务实现 iOS；Android、桌面、Web 留作后续独立任务。
- Flutter/iOS 仅做薄 UI、启动适配与测试驱动，不复制 CLI 状态机。
- 最终验收不得依赖 mock 市场、内置插件、假返回或 UI toast。
- 真机保留签名、Keychain 与系统能力 smoke，不再是核心验证唯一入口。

## 完成定义

只有 `ACCEPTANCE.md` 全部勾选且有可复核代码、自动测试、CI 和真实线上证据，任务才能报告全部完成。
